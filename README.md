# Blogify

**Blogify** is my personal blogging space - Because I don't want to use a third-party tool to post my unhinged thoughts :)

## 🚧 Status

- **Comment Section**: The comment section has been added.
- Currently working on to optimize the Lighthouse score.

## 🧠 Why Blogify?

I wanted a space that:
- Reflects my personality and creative freedom.
- Doesn't rely on bloated CMS platforms.
- Is developer-friendly and fully customizable.

A minimalist, distraction-free blogging platform that feels personal and powerful — without the clutter of traditional CMS tools.
